# Coaching packages run two clocks from the first visit

A coaching package bundles coached sessions (valid 7–45 days, depending on the package) with one month of Monthly membership. The two run on separate clocks, and both start at the **package start**: the client's first check-in or first coaching session, or automatically 15 days after payment approval. They don't start at the purchase, the approval, or the start date picked at sign-up, because clients often pay through Facebook days or weeks before they first come in. The membership month is added after any membership already paid for, so an existing member never loses days. A freeze pauses only the coaching clock; the membership month keeps running.

## Considered Options

- One shared expiry for coaching and gym access: rejected, because the gym sells packages as "coached sessions plus a full month of gym use", and short packages (7 days) would otherwise cut gym access short.
- Starting at the chosen start date or at approval: rejected, because clients would lose paid days before their first visit. The 15-day automatic start keeps unused packages from staying open forever.
